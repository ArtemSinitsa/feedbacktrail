FeedbackTrail · Прозрачная оценка

Комментарии к оцениванию по рубрике → утверждение преподавателем → личный кабинет студента → апелляция
MVP · только синтетические данные. Имитируемые компоненты: (1) хранение — в этом браузере (localStorage) вместо сервера; (2) вход студента по ID + коду доступа вместо университетского SSO; (3) «публикация» видна только в этом браузере. Логика рубрики, черновиков, утверждения, версий, контрольных сумм и апелляций — реальная.
